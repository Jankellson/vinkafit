## SOLIS 4 — AEO / AI search visibility

### 🟢 AI-friendly satura struktūra (katram rakstam)
```
1. ✅ Tūlītēja atbilde 1. paragrāfā (40–60 vārdi) → tad detalizācija
2. ✅ H2 jautājuma formātā ("Kā...", "Kas...", "Kāpēc...")
3. ✅ FAQ sadaļa (Q&A — AI mīl) + FAQPage schema
4. ✅ Listes un tabulas (viegli citējami)
5. ✅ Konkrēti dati ar avotu citējumiem (inline)
6. ✅ Schema: Article + Person + FAQPage (+ LocalBusiness kontaktiem)
7. ✅ Autora bio ar credentials
```

### 🟡 Reverse-engineer ChatGPT vaicājumus (spēcīgākā GEO kustība)
ChatGPT atbildot meklē ar SAVIEM vaicājumiem. Noķer precīzo valodu → ieliec 4 vietās:
```
Prompt ChatGPT par tēmu (trigerē web search) → chat URL pēc /c/ → Inspect → Network →
ielīmē URL daļu filtrā → Refresh → ieraksts ar oranžiem brackets → Response → meklē "queries".
Atkārto ~10 promptiem ("labākais uztura speciālists Latvijā", "insulīna rezistence uzturs" u.c.)
→ savāc atkārtotās frāzes → liec page titles/slugs/H2/1. teikumā.
```

### 🟡 Kur katrs AI dzinējs meklē
| Dzinējs | Uzvedība | Sekas Ievai |
|---|---|---|
| **ChatGPT** | 3 boti, cache ~3-4 ned; lasa meta description | Aizpildi meta description; lokālā schema palīdz |
| **Claude** | **Brave Search** (ne Google) | Pārbaudi Brave pozīciju atsevišķi |
| **Perplexity / Grok** | Live search | Turi lapas svaigas (datumi, atjauninājumi) |
| **Google AI Overviews** | Google rankings + ļoti citē **YouTube** | Listicles, salīdzinājumi + video uzvar |

**Lokālā schema = ChatGPT svira, NE Google** (Jake Hundley 2025, >92%): LocalBusiness schema neko nedod Google
rankingam, bet uzlabo ChatGPT redzamību (+~3 poz.). Pievieno (lēti), bet nepaļaujies Google rankingam.

## SOLIS 6.5 — Off-page / saišu veidošana (viss WHITE HAT)

### 🟢 Kas ir laba saite
Augsts DR + reāls trafiks · DoFollow · kontekstuāla (raksta ķermenī) · tematiski relevanta (veselība/dzīvesstils) · unikāls domēns.
> **Unlinked mentions ≈ backlinks** (Mike King/Rand): pieminēšana BEZ linka tikpat svarīga E-E-A-T + AI konsensam.

### Taktikas
```
1. Digital PR / linkbait (spēcīgākā): citējams data-asset (pašu aptauja Ievas IG auditorijā —
   piem. "Cik latviešu zina savus asinsanalīžu rādītājus") → pitch DELFI/LSM/TVNET/veselības mediji
   (Kaszoni formāts: treknraksta 1. rinda, 3-4 bullet, statistika+tabula, unikāls citāts no Ievas, metodoloģija).
2. 🟡 Broken link building (Ahrefs Outbound → Broken) uz veselības lapām.
3. 🟡 Link Intersect + Content Gap (kas saista uz Zani/Kristiānu, bet ne uz Ievu).
4. 🟡 Guest post (veselības/dzīvesstila blogi, podkāsti — Ievas skolotājas balss der intervijām).
```
