### ⚠️ Publicēšanas secība — Spokes → Hub (lielākā daļa kļūdās)
```
❌ Hub pirmais → Google atrod "orphan" (bez ienākošām saitēm) → zems autoritātes signāls.
✅ 1. mēn: 3-4 spoke lapas → 2. mēn: hub (uzreiz saista uz spokes) → 3-4. mēn: atlikušās spokes → atpakaļ uz hub.
```

### Iekšējo saišu noteikumi
```
SPOKE → HUB: pirmā saite = visvērtīgākā. Kontekstuāla (raksta ķermenī, 1.-2. paragrāfā),
             aprakstošs anchor ("uztura plāns insulīna rezistencei", NE "klikšķ šeit").
HUB → SPOKE: saista uz KATRU spoke ("Saistītie raksti" / satura rādītājs).
SPOKE → SPOKE: taupīgi (max 2-3, tikai ja dabiski).
ĀRĒJĀS: hub lapai 3-5 saites uz autoritatīviem avotiem (pētījumi, PVO, EFSA — NE konkurenti).
+ KATRS spoke → saite uz attiecīgo PRODUKTU/lead magnetu (biznesa modelis: saturs = dzinējs).
```

## SOLIS 5.8 — SXO / SERP pre-write check ("Lasi SERP atpakaļ")
> Dari PIRMS katra raksta. SERP jau kodē, kādu lapas TIPU Google atalgo. Nesakrīt → nekāds tweak nepalīdz.
```
1. Google incognito (LV/RU) → meklē primāro atslēgvārdu
2. Klasificē top-10 pēc tipa {how-to, definition, listicle, comparison, product, forum, video, landing}
3. Dominējošais tips ≥6/10 → taisi TO formātu. 4-4 → split-intent.
4. SERP features: AI Overview/PAA → informatīvs · Shopping/Ads → komerciāls · Video carousel → vajag video.
5. Salīdzini savu plānoto tipu ar dominējošo → nesakrīt → MAINI formātu PIRMS raksti.
```
4 personu lēca: Skimmer (tabulas/virsraksti) · Researcher (dziļums+avoti) · Buyer (cena/salīdzinājumi) · Validator (akreditācija/datumi).

> Formāts: informācijas lapas (ne blogi) — evergreen, bez datuma, H2/H3. URL: `/uztura-abc/[slug]` ·

intermitējoša gavēšana · hormoni-svars · kortizols · miegs-svars
