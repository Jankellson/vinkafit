  "holesterīns un kafija", "ēdienkarte/receptes holesterīna samazināšanai"  ← daudz "vai X drīkst" spoke lapas
- "uztura speciālists liepājā/valmierā/ventspilī/jelgavā/rēzeknē/cēsīs/ogrē/tukumā/madonā/kuldīgā"  ← service×city
- "kaloriju deficīts ēdienkarte / receptes / kalkulators"
- "veselīgas brokastis sievietēm / receptes" · "ko ēst vakariņās lai notievētu"
- "homa indekss kas ir / paaugstināts / insulīna rezistence" · "cik olbaltumvielas jāuzņem dienā"
RU:
- "почему вес стоит на месте при правильном питании / при дефиците калорий / после родов"  ← milzīgs klasteris
- "индивидуальный план питания купить / сколько стоит / онлайн"
- "инсулинорезистентность питание меню / лечение питанием"
- "как похудеть после 40 без спорта / в домашних условиях"
```

## 🟡 Zero Search Volume (ZSV) atslēgvārdi
LV+RU mazi apjomi → daudz vērtīgu vaicājumu rādās kā "0 meklējumu". Validē PIRMS raksti:
```
□ GSC: vai lapa jau saņem clicks/impressions par šo? (Keywords Everywhere ext.)
□ Forumi (calis.lv, mammamuntetiem.lv), Reddit r/Latvia, FB grupas: vai cilvēki to jautā?
□ Pajautā Ievas IG auditorijai (5k) / e-pasta listei (kad būs)
```
ZSV zelts: specifiski analīžu rādītāji (homocisteīns, HbA1c, CRP uzturs) + segmentu niansas.

## 🟡 SEO Avalanche — prioritizē pēc trafika līmeņa

```

## 🟢 1 atslēgvārds → 4 vietas + viegluma tests (Edward Sturm)
**A) Katra lapa = VIENS primārais atslēgvārds 4 vietās:** (1) URL slug · (2) H1 sākums · (3) meta description
pirmajos ~10 vārdos · (4) 1. teikums. Divas lapas NEDRĪKST mērķēt vienu atslēgvārdu (kanibalizācija).
Tās pašas 4 vietas baro arī ChatGPT/Claude izguvi. → Izpilde un tracker: [03-OnPage.md](03-OnPage.md).

**B) Viegluma tests:** Google incognito (LV/RU) → meklē → skaties top-10 vai konkurenti liek atslēgvārdu tieši
šajās 4 vietās. NEaizpilda → viegls, ņem. Visi aizpilda → garāks long-tail. (Sasaucas ar SXO — [04](04-Saturs.md).)
